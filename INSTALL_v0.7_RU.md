# Установка v0.7

1. Распакуйте архив.
2. Скопируйте всё содержимое папки обновления в локальный репозиторий.
3. Подтвердите замену файлов.
4. В GitHub Desktop используйте Summary:

`Pin verified STON.fi pools`

5. Commit to main.
6. При запросе сначала Fetch/Pull, затем Push origin.
7. Дождитесь зелёного GitHub Actions.
8. Откройте `data/collector-report.json`.

Ожидаемый результат для STON.fi: `updated: 2`.
