# Что потребуется от Вадима

Вся подготовка, которую можно выполнить без доступа к вашим аккаунтам, завершена.
Следующий шаг требует загрузки файлов в ваш GitHub и привязки сайта.

## Вариант A — самый простой: новый репозиторий GitHub

1. Откройте GitHub и создайте новый пустой репозиторий.
2. Назовите его, например, `ton-defi-believers`.
3. Не добавляйте README, `.gitignore` и лицензию: они уже есть в архиве.
4. Распакуйте архив v0.5 на компьютере.
5. Загрузите всё содержимое распакованной папки в репозиторий.
6. Откройте вкладку **Actions** и разрешите GitHub Actions, если GitHub попросит.
7. Запустите workflow **Update DeFi data** кнопкой **Run workflow**.
8. Пришлите ссылку на репозиторий или снимок результата первого запуска.

## Netlify

После успешного GitHub Actions:

1. В Netlify выберите **Add new site → Import an existing project**.
2. Выберите созданный GitHub-репозиторий.
3. Netlify автоматически прочитает `netlify.toml`.
4. Проверьте:
   - Build command: `npm run build`
   - Publish directory: `public`
5. Нажмите **Deploy**.
6. Пришлите полученный адрес вида `название.netlify.app`.

## Необязательный бесплатный RPC-ключ

Без него первый запуск допустим. Позже для более стабильного on-chain чтения:

1. Получите бесплатный TON Center API key.
2. В GitHub откройте:
   **Settings → Secrets and variables → Actions → New repository secret**.
3. Название: `TONCENTER_API_KEY`.
4. Вставьте ключ и сохраните.

Никогда не присылайте API-ключ в чат и не добавляйте его в файлы репозитория.

## Что будет проверено после вашего шага

После получения ссылки на репозиторий или Netlify нужно будет:

- посмотреть первый реальный `collector-report.json`;
- проверить список кандидатов STON.fi;
- привязать точные пулы;
- проверить ответ DeDust API;
- включить подтверждённые Tonstakers и EVAA метрики;
- подключить on-chain getters Hipo и Bemo;
- встроить JSON в существующий дизайн сайта;
- проверить русский и английский интерфейс;
- выполнить финальный аудит ссылок и мобильной версии.
