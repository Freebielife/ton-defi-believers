# v8 — перестройка каталога

## Что изменилось

- Главным объектом сайта стала конкретная доходная возможность, а не протокол.
- В каталоге 30 продуктов и пулов из 14 протоколов.
- Для каждой строки обязательны текущая доходность, среднее за 7 дней и TVL.
- TVL ниже $10 000 отмечается как низкий.
- Utilisation Rate показывается только там, где он опубликован.
- По умолчанию строки сортируются по TVL.
- Сортировка по доходности доступна, но не называется рейтингом лучших вариантов.
- Возможности сгруппированы по активам.

## Источник

Начальный снимок соответствует публикации TON Yields Daily №229 от 28 июля 2026 года, 10:19 UTC.

GitHub Actions пытается импортировать свежую публичную публикацию. При ошибке сети сохраняется предыдущий файл `data/market-catalog.json`.
