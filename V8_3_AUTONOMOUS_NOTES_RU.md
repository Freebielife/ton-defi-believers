# TON DeFi Believers v8.3 — автономные данные

## Что изменено

- TON-сайт больше не зависит только от JSON, зашитого в TON Storage bag.
- При открытии сайт сначала мгновенно показывает локальный резервный снимок.
- Затем он запрашивает актуальный `market-catalog.json` из репозитория GitHub.
- Проверяются два независимых публичных адреса: GitHub Raw и GitHub Pages.
- Из доступных вариантов выбирается самый свежий снимок по времени публикации.
- Если GitHub временно недоступен, сайт продолжает работать на локальном снимке.
- Пока страница открыта, повторная проверка выполняется каждые 10 минут, а также после возвращения на вкладку или восстановления интернета.
- На странице явно отображается режим: «Онлайн-данные» или «Резервный снимок».

## Автоматическое обновление

GitHub Actions запускает сборщик каждый час, на 17-й минуте. Если источник опубликовал новые данные, JSON в репозитории обновляется автоматически. TON-сайт получает этот JSON при следующем открытии или фоновой проверке без создания нового BagID.

## Что больше не нужно делать вручную

Для обычного обновления ставок не нужно повторно загружать папку в Resistance Tools и менять TON DNS. Повторная публикация нужна только при изменении HTML, JavaScript, CSS, логотипов или структуры сайта.

## Резервный режим

Локальный `data/market-catalog.json` остаётся внутри TON Storage. Он нужен, чтобы интерфейс и каталог продолжали открываться при недоступности GitHub. Возраст снимка всегда показывается пользователю.
