# TON DeFi Believers v8.2 Final

Финальная пилотная сборка простого статического каталога доходности TON DeFi.

## Интерфейс

- фирменный логотип в шапке;
- локальные иконки протоколов;
- кликабельные названия проектов;
- без отдельной колонки перехода;
- градиентный фон и цветовые акценты категорий;
- компактная таблица и мобильные карточки;
- поиск, фильтрация, сортировка, RU/EN;
- текущая доходность, среднее за 7 дней, TVL и предупреждение о низком TVL;
- отсутствие реферальных параметров.

## Обновление

- GitHub Actions запускается после изменения кода и каждый час;
- используется Node.js 24;
- `actions/checkout@v6` и `actions/setup-node@v6`;
- при ошибке источника сохраняется последний успешный снимок;
- `RESISTANCE_UPLOAD` автоматически синхронизируется с `public`.

## Публикация

- GitHub Pages публикует папку `public`;
- Resistance Tools получает распакованную папку `RESISTANCE_UPLOAD`;
- сервер и база данных не требуются.
