# Обновление TON DeFi Believers до v0.6

Эта версия исправляет причину, по которой STON.fi получил 47 042 пула,
но не нашёл ни одного совпадения.

## Что изменено

Предыдущий адаптер искал символы токенов непосредственно внутри записей пулов.
В реальном ответе API пулы могут содержать главным образом адреса активов.

Новый адаптер:

1. Загружает официальный каталог `/v1/assets`.
2. Создаёт таблицу `адрес актива → символ`.
3. Загружает отдельно пулы STON.fi V1 и V2.
4. Преобразует адреса активов пула в символы.
5. Ищет пары с поддержкой алиасов `tsTON/TSTON`, `USDT/USD₮`.
6. Загружает активные farms как дополнительный источник APR/APY.
7. Не публикует неоднозначный результат.
8. Создаёт расширенный диагностический отчёт.

## Как установить

1. Распаковать ZIP.
2. Открыть папку `ton-defi-believers-update-v0.6`.
3. Скопировать всё содержимое этой папки.
4. Вставить в локальную папку GitHub-репозитория `ton-defi-believers`.
5. Согласиться на замену существующих файлов.

В GitHub Desktop должно появиться около 7 изменённых/новых файлов.

Summary:

```text
Improve STON.fi pool discovery
```

Затем:

```text
Commit to main
Push origin
```

После Push GitHub Actions запустится автоматически. Если не запустится:

```text
Actions → Update DeFi data → Run workflow
```

## Что прислать после запуска

Нужен один файл или его содержимое:

```text
data/stonfi-candidates.json
```

Можно открыть его прямо в GitHub:

```text
Code → data → stonfi-candidates.json
```

Также подойдёт ссылка на этот файл.

## Ожидаемый результат

В верхней части файла должны появиться поля:

- `assetsReceived`
- `v1PoolsReceived`
- `v2PoolsReceived`
- `resolvedPoolSymbols`

А в `candidates` должны появиться найденные варианты для отслеживаемых пар.
После этого можно будет безопасно закрепить точные адреса пулов.
