# TON DeFi Believers v1.0

## Первый стабильный релиз агрегатора

Добавлено:

- Yield Score от 0 до 100;
- рейтинг возможностей в `data/rankings.json`;
- тренды доходности и TVL за 1, 7 и 30 дней;
- поисковый индекс в `data/search-index.json`;
- готовые фильтры по протоколу, активу, категории, типу и риску;
- сортировка по Yield Score без обращения к внешним API;
- только проверенные активные возможности попадают в поисковый индекс;
- тесты формулы рейтинга и исторических окон;
- сохранена совместимость с текущим сайтом.

Yield Score учитывает:

- доходность — до 35 баллов;
- Confidence — до 30 баллов;
- глубину TVL — до 20 баллов;
- обратный риск — до 15 баллов.

Экстремально высокая доходность намеренно не может полностью
доминировать в рейтинге.

## Что нужно сделать

1. Распаковать ZIP.
2. Скопировать папку `ton-defi-believers-update-v1.0`
   в репозиторий с заменой файлов.
3. В GitHub Desktop написать:

```text
Release v1.0 ranking and search
```

4. `Commit to main`.
5. `Fetch/Pull`, если GitHub Desktop это предложит.
6. `Push origin`.
7. Дождаться зелёного workflow `Update DeFi data`.

## Что прислать

Из `data/rankings.json`:

- первые три объекта из массива `opportunities`.

Из `data/search-index.json`:

- поля `count` и `facets`.

Полные файлы не нужны.
