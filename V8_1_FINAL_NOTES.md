# TON DeFi Believers v8.1 Final

Final pre-publication build for GitHub Pages and Resistance Tools.

## Visual changes

- Compact hero block so the catalog appears earlier.
- Summary now shows opportunities, protocols, low-TVL entries and snapshot time.
- Current yield and 7-day average are combined in one column.
- Utilisation rate is shown only for products that publish it.
- Repeated per-row update time is hidden on mobile; the global snapshot time stays visible.
- Sticky table headers and compact mobile cards.

## Data wording

TON DeFi Believers is presented as an independent aggregator. Official protocol sources and APIs are used where available. TON Yields Daily supports daily market monitoring and cross-checking and is not described as the sole source of yield data.
