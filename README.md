# TON DeFi Believers — static TON DeFi overview

Простой статический сайт для быстрого знакомства с выбранными возможностями DeFi в TON.

- 15 протоколов и 15 понятных записей;
- без сервера и базы данных;
- данные публикуются в статических JSON;
- обновление выполняет GitHub Actions;
- при сбое источника сохраняется предыдущий успешный снимок.

## Версия v6

Основные изменения касаются двух главных DEX:

- **STON.fi:** точечный запрос выбранного пула, 7-дневный APY, TVL из официального поля и on-chain сверка резервов;
- **DeDust:** выбран пул TON/USDT, исправлено распознавание активов, добавлен расчёт fee APR за полные 7 дней и on-chain сверка резервов/комиссии;
- на сайте видны период показателя и время обновления.

Подробности расчёта: `V6_DATA_NOTES.md`.

## Запуск проверки

```bash
npm run test:adapters
npm run build
```

Для on-chain проверки можно добавить GitHub Secret `TONCENTER_API_KEY`. Сервер для сайта не требуется.
