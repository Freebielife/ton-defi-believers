# TON DeFi Believers Collector v0.4

В этой версии устранено главное логическое противоречие: наличие файла-адаптера
больше не называется полной автоматической интеграцией.

## Статусы

- `automatic` — данные уже могут обновляться автоматически;
- `automatic-catalog` — автоматически загружается каталог, но конкретные позиции
  публикуются только после привязки адресов;
- `sdk-ready` — официальный SDK подтверждён;
- `api-ready` — официальный API найден, требуется закрепить endpoint и схему;
- `onchain-ready` — официальные контракты или формула подтверждены;
- `manual` / `source-pending` — ручной режим без выдуманного источника.

Фронтенд может читать:

```text
data/integration-status.json
```

## Подтверждённые интеграционные возможности

- Tonstakers SDK: APY, исторический APY, TVL, rates, instant liquidity;
- EVAA SDK и контракты: конфигурация и динамика активов, supply/borrow rates;
- Hipo: официально опубликованы Treasury и Parent mainnet-контракты;
- Bemo: официально описана формула отношения staked TON к supply bmTON.

## Безопасность данных

Collector не угадывает:

- getter-методы контрактов;
- mainnet-адреса;
- единицы rate;
- APR/APY;
- соответствие пула по одному названию.

До подтверждения старое значение сохраняется и явно помечается как неавтоматическое.

## Бесплатная работа

Сохраняется прежняя архитектура: GitHub Actions + статические JSON.
RPC-ключ необязателен; при необходимости его можно добавить как бесплатный
GitHub Secret `TONCENTER_API_KEY`.
