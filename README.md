# TON DeFi Believers — TON DeFi market catalog

Простой статический сайт для быстрого обзора рынка DeFi в TON.

- около 30 конкретных продуктов и пулов вместо одной строки на протокол;
- текущая доходность и среднее значение за 7 дней;
- TVL для каждой возможности;
- предупреждение при TVL ниже $10 000;
- группировка по GRAM, стейблкоинам, GRAM–USDT, BTC и ETH;
- без сервера и базы данных;
- публикация через GitHub Pages;
- обновление рыночного снимка через GitHub Actions с сохранением последней успешной версии при ошибке источника.

## Версия v8

Главный файл каталога: `data/market-catalog.json`.

Источник текущего рыночного снимка: публичный канал TON Yields Daily. Импортёр находится в `collector/import-ton-yields-daily.mjs`. Если публичная страница Telegram временно недоступна, сборка не удаляет предыдущий успешный снимок.

## Проверка

```bash
npm run test:adapters
npm run sync:public
npm run release:check
```

Полный автоматический цикл:

```bash
npm run build
```

Сервер для сайта не требуется.
