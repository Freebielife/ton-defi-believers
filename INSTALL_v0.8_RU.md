# Обновление v0.8 — полноценный каталог DeDust

## Что сделано

- подключён официальный endpoint `https://api.dedust.io/v2/pools`;
- добавлена нормализация нескольких вариантов ответа API;
- распознаются stable и volatile pools;
- извлекаются TVL, APR/APY, объём за 24 часа и комиссия, если API их отдаёт;
- создаётся независимый снимок `data/protocols/dedust.json`;
- сохраняется совместимый файл `data/dedust-pools.json`;
- добавлена безопасная привязка пулов по адресам активов;
- добавлены тесты против подмены токенов;
- STON.fi и DeDust теперь имеют отдельные протокольные выходы;
- диагностические JSON копируются в `public/data`.

В текущем `opportunities.json` нет DeDust-позиций, поэтому v0.8 пока не
добавляет выдуманные карточки. Сначала Collector должен показать реальную
структуру каталога и доступность TVL/yield.

## Установка

1. Распаковать архив.
2. Скопировать всё содержимое папки обновления в локальный репозиторий.
3. Подтвердить замену файлов.
4. Summary в GitHub Desktop:

```text
Add DeDust protocol catalog
```

5. Commit to main.
6. При запросе выполнить Fetch/Pull.
7. Push origin.
8. Дождаться зелёного GitHub Actions.

## Что прислать

Открыть:

```text
data/collector-report.json
```

и прислать только объект с:

```json
"adapter": "dedust"
```

Также полезен верхний блок:

```text
data/protocols/dedust.json
```

Достаточно полей `summary`, без полного списка пулов.
