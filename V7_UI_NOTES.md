# v7 — Visual and mobile revision

This build changes only the public presentation layer.

- Mobile market rows are rendered as clear cards.
- The product, yield, TVL and source status remain visible without horizontal scrolling.
- The protocol link is a full-width Open / Открыть button on mobile.
- Missing links are disabled instead of producing an invalid URL.
- A verification note is shown when no shorter yield note is available.
- The duplicated protocol-description grid is hidden on mobile to keep the pilot page short.
- No server, database or new product feature was added.
