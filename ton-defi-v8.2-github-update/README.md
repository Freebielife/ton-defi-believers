# TON DeFi Believers — TON DeFi market catalog

Простой статический сайт для быстрого обзора рынка DeFi в TON.

- около 30 конкретных продуктов и пулов вместо одной строки на протокол;
- текущая доходность и среднее значение за 7 дней;
- TVL для каждой возможности;
- предупреждение при TVL ниже $10 000;
- группировка по GRAM, стейблкоинам, GRAM–USDT, BTC и ETH;
- без сервера и базы данных;
- кликабельные названия протоколов и локальные логотипы;
- лёгкая градиентная визуальная тема без внешних изображений;
- публикация через GitHub Pages и статическую сборку для Resistance Tools;
- ежечасная проверка обновлений через GitHub Actions с сохранением последней успешной версии при ошибке источника.

## Версия v8.2

Главный файл каталога: `data/market-catalog.json`.

Каталог объединяет официальные источники и API там, где они доступны. TON Yields Daily используется для мониторинга и сверки рыночного снимка, но не обозначается как единственный источник. Импортёр находится в `collector/import-ton-yields-daily.mjs`. Если источник временно недоступен, сборка не удаляет предыдущий успешный снимок.
