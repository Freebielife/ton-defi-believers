# TON DeFi Believers — состояние пилота v6

- Один статический сайт без сервера и базы данных.
- 15 выбранных TON DeFi-протоколов.
- По одной понятной возможности на протокол.
- STON.fi запрашивается по точному адресу пула; основной показатель — 7-дневный APY.
- DeDust отслеживает конкретный пул TON/USDT; fee APR рассчитывается за полные 7 дней.
- Резервы STON.fi и DeDust сверяются через TON RPC, когда он доступен.
- При ошибке API сохраняется предыдущий успешный снимок.
- На сайте видны тип/период доходности и дата обновления данных.
